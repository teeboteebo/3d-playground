# Bedroom Visualizer → React app (implementation plan)

Spec: `docs/superpowers/specs/2026-11-04-react-app-design.md`

1. **Scaffold**: `package.json`, `vite.config.ts` (base `/3d-playground/`), `tsconfig*.json`,
   `eslint.config.js`, root `index.html` (fonts + `#root`), `.gitignore`, `.nvmrc`.
   The original stays in git history; a copy is served locally for side-by-side comparison.
2. **Pure modules + tests first**: `lib/color.ts`, `state/settings.ts`, `scene/layout.ts`,
   `scene/palette.ts`, `data/catalog.ts` with Vitest unit tests (sanitising old saved
   settings, `mould: 'off'` migration, slider clamping, hex validation, layout clamps).
3. **Scene**: port textures and room construction into `scene/textures.ts` and
   `scene/createScene.ts`, with `apply`, `setView` and `dispose`.
4. **UI**: React components reproducing the original markup/classes; `styles.css` copied verbatim.
   Component tests with `createScene` mocked: chips toggle `aria-pressed`, accent input
   validation, moulding toggle disables the slider group, rug selection, persistence, no-WebGL fallback.
5. **CI/CD**: `ci.yml` (npm ci, lint, typecheck, test, build) on PR + main;
   `deploy.yml` builds and deploys `dist/` to Pages on main. Switch the Pages source to Actions.
6. **Prove**: run lint/typecheck/test/build; run the app in the browser and compare
   screenshots with the legacy page (overview, evening lighting, each view, rug change, mobile width).
7. **Ship**: PR, review loop, CI green, merge, confirm the Pages deploy.
